# BUG-03: Буруу JSON/биетэй API POST хүсэлтэд HTTP 400 алдааны заалт буцаахгүй байна

Орчин:  Уншлагын жагсаалт v2.0, curl, macOS, 2026-10-15
Урьдчилсан нөхцөл: node app.js-ийг шинээр асаасан

## Дахин гаргах алхам
1. Терминал дээр дараах командыг ажиллуулна:
   `curl -i -X POST localhost:3000/api/books -d 'invalid_payload'`
2. Системээс ирж буй HTTP хариуны статус кодыг шалгана.

Хүлээгдэж байсан: Буруу JSON эсвэл хүчингүй өгөгдөлтэй POST хүсэлтэд HTTP Status 400 (Bad Request) буцаах ёстой.
Бодит үр дүн:     Систем HTTP/1.1 200 OK болон {"result":"OK"} буцааж байна.

Ноцтой байдал: Major - API контракт болон баталгаажуулалтын доголдол.
