## Дүгнэлт (Debrief)
Couch Potato болон Saboteur аялалуудыг хослуулан ашигласнаар GUI болон backend API түвшний согогуудыг амжилттай илрүүлж чадлаа. Couch Potato аялалын хүрээнд форм дээрх утгын хязгаарлалтууд (жишээ нь, оны талбарт хасах тоо зөвшөөрөгдөх, хоосон мөр нэмэгдэх) алдагдсан байгааг олж тогтоосон. Зарим хайлтын функциональ болон устгах товчны өнгө санамсаргүй байдлаар шалгагдав. Saboteur аялалын хүрээнд curl ашиглан буруу хүсэлт явуулахад API нь HTTP status 400 буцаах ёстой спецификацийг зөрчин HTTP 200 OK мэдээлж байгааг илрүүлсэн. UI дээрх validation-ий зарим алдаанууд Лаб 1-ийн Playwright автомат тестээр амархан баригдах боломжтой бол, API-ийн логик болон HTTP хариу кодын зөрчлүүд зөвхөн хүний нүд болон exploratory тестийн явцад илрэх боломжтой юм. SBTM аргачлал нь богино хугацаанд системийн чухал согогуудыг системтэйгээр баримтжуулахад маш үр дүнтэй байлаа.
